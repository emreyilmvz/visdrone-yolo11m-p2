## VisDrone-DET2019

- Ultralytics dataset documentation (license field says “No license”): https://docs.ultralytics.com/tr/datasets/detect/visdrone
- Dataset Ninja entry and disclaimer: https://datasetninja.com/vis-drone-2019-det

The dataset is not included in this repository. Obtain it from the [official VisDrone dataset repository](https://github.com/VisDrone/VisDrone-Dataset) and follow the terms that apply to the specific release. Ultralytics documents the dataset download/conversion process, but its page marks the license as “No license.” Dataset Ninja labels it “publicly available,” but its disclaimer says it claims no rights to the source content and places license and permission checks on the user. Public availability is not a redistribution license. The official 2019 repository README does not state a license, so confirm permission and attribution requirements with the dataset provider before reuse or redistribution. The provider's separate VisDrone2021 policy must not be assumed to govern the 2019 release.
